# Campus Lost & Found

A full-stack web application that helps students report lost items and find items discovered on campus.

## Features

- Report lost and found items.
- View all reported items.
- Search and filter items.
- Update item details and status.
- Delete item reports.
- Store item information in MongoDB.

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose

## Prerequisites

- Node.js and npm
- A MongoDB database
